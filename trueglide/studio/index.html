Mode d'emploi

  1. Flasher le firmware TrueGlide avec Betaflight Configurator (onglet « Flasher », « Charger le firmware [local] », fichier trueglide_…hex, case « Effacement complet »).
  2. Refaire la configuration de base : ports, récepteur, modes (dont SPEEDER si besoin), OSD.
  3. Dans Studio : décrire le drone, « Calculer le réglage », « Copier », puis coller dans l'onglet CLI du Configurator et valider avec Entrée (la commande save est incluse).
  4. Premier essai sans hélices : onglet Moteurs, vérifier l'ordre et le sens des moteurs. Puis hélices, stationnaire court, et toucher les moteurs.
  5. Ajuster avec les curseurs de l'onglet PID du Configurator (le curseur maître d'abord, par pas de 5).

Les réglages ESC (AM32, BLHeli_32, BLHeli_S, Bluejay) se font comme avant avec ESC Configurator ou BLHeliSuite, par la FC (passthrough) : TrueGlide garde cette fonction de Betaflight.
