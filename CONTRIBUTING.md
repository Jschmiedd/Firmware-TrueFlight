# Contribuer à TrueGlide

TrueGlide est un projet personnel de TalkTrueFPV. Les tickets (onglet **Issues**) sont les bienvenus pour signaler un
problème ou proposer une amélioration. Pour un problème, indiquer :

- le firmware (TrueGlide, TrueNav ou TrueNav Light), sa version et la carte ;
- le texte de `diff all` (onglet CLI) et, si possible, un journal blackbox ;
- comment reproduire le problème.

Les demandes de fusion (pull requests) sont lues, sans garantie d'intégration. Tout code proposé est sous GPL-3.0.
